# 后续coding agents执行约定 · 基线2.0

本文件适用于未来**已获用户授权的产品实施**。当前包仅有设计文档与静态原型，其存在不构成产品编码授权。不得在本设计目录铺设Rust/Tauri/React产品项目。

## 开始与阅读顺序

1. 阅读README、审查与修订记录，再读01–08业务设计、11实施契约、12页面操作追踪、09视觉、10任务清单。
2. 核对“文件清单与摘要.json”和包SHA256，记录设计版本2.0。1.0已被替代，旧ZIP仅供历史比较。
3. 机器可读规范：设计契约/命令目录.json（65命令）、页面操作追踪.json（38组UI操作）、视觉令牌.json。字段名/enum/版本不可按各自习惯改写。
4. 用户范围优先；行为细化以11/12为准，原型只是视觉示例。契约JSON与正文冲突先记录并修正，不任选有利版本；视觉以token→09→HTML顺序执行。
5. 实施工作在本仓库根目录展开，设计目录docs/design/v2.0保持只读基线。先做T00–T06，建立固定版本样本、schema/IPC映射、Windows环境和依赖锁定记录。是否继续后续阶段按用户已有授权范围；已授权全量实现且门禁通过可继续，无需每阶段重复询问。

## 固定范围与实现边界

- Windows11 x64，Rust核心/Tauri2边界/React展示，本地个人用。Minecraft下载是P0硬要求，不能以仅导入、只启动已有文件或PCL后来的变动替代。
- M0基础门和认证门分开；认证待批时可推进已通过基础门的独立任务，但不能虚报M0/M3或P0整机完成。自有client ID，不借用他人启动器身份。
- 依赖族：tokio/reqwest/serde/rusqlite（单独DB工作线程）/tracing，TanStack Query+React局部state；确切版本实施当天核查。改变库族或关键行为要ADR。
- Windows DPAPI用户范围secret文件；原生凭据输入。token、proxy密码、CF key不经过React，不写DB、日志、fixture或导出。
- 真实版本和Java按元数据及Loader约束。HTML的javaFor、样例账号、组件构建、速度和尺寸是演示数据，禁止移植到产品业务判断。
- 所有副作用在Rust，Tauri capability不替代参数/路径/状态校验；远程描述不能调用IPC；不拼shell命令，不执行整合包脚本。
- 计划不可变，预览/摘要/幂等/过期/revision严格按11。接受计划后独占实例mutation lease；运行lease互斥。任务100%不是Ready。
- Task与TaskExecution分开，失败重试新execution，旧错误保留。Canceled/Succeeded不能复活。事件游标补拉与非持久progress_seq分开。
- 文件提交必须逐entry journal，DB事务不能替代文件回滚；使用11恢复判定，不凭时间戳猜。共享缓存到可变区域统一复制，无可写硬链接。
- 保全存档、未知Mod和外部新增文件。PCL/官方目录只读扫描后复制；导入失败不得清源目录，不迁入凭据。备份恢复v1仅为新实例。
- 默认无遥测，AI为M7。真实构建不得静默回退到mock成功；没有验证的功能必须显示未开放/尚未验证。

## 每个任务的完成定义

1. 写明T、FR、UI-ID、规范命令、ADR、AC，不以“页面已经画好”替代功能完成。
2. 输入输出按同一DTO字典和fixture；读取型、计划型、变更型分开。mock要明确标记并从真实构建移除。
3. 完成成功/失败/取消或重启的关键路径验证。安全解析、Range、journal与状态竞态须故障注入；没有Windows实测只能报告模块检查。
4. 每个可见按钮有真实命令或明确的前端行为；pending/disabled/错误原因齐全。UI上下文按UUID，不按显示名；设置草稿不可无提示丢弃。
5. 视觉必须遵循token与组件状态，不能把HTML截图当背景。AC40要求目标窗口、深色、键盘/缩放证据。设计工具条和模拟按钮不得带入产品。
6. 报告实际修改范围、证据路径、未通过AC、设计差异与回退方式。AC01–40仍待实现和执行；本设计包的浏览器检查不是产品验收。

## 协作与集成

若用户明确授权多agent工作，指定schema/IPC集成负责人；按模块分配不重叠文件。共享契约先冻结，修改需负责人合并并更新所有消费者；不得各自维护一份不同DTO。未获授权不自行创建额外用户聊天或发送消息。

阻塞只阻塞依赖链，继续可独立验证的任务。外部条件未满足不得删除验收要求、关TLS、跳过hash、扩大路径权限或绕过认证来“完成”。范围缩减由用户明确决定；普通实现细节在已授权范围自主处理。
