# K Launcher · Windows 11 Minecraft Java 启动器设计交付包

设计基线2.0 / 2026-10-22（北京时间）

本包为本地个人使用的Rust + Tauri 2 + React启动器提供完整设计规格和高保真静态原型。**只制作设计文档，没有开始产品编码。** 下载Minecraft是P0硬性需求，AI后置，不建立分发或遥测服务。

2.0已替代1.0。先看[复审与变更](审查与修订记录.md)；新版强化协议一致性与agent交接，仍未开始产品编码。

## 先打开这两个文件

1. [设计总册.html](设计总册.html)：十二份中文规格合并阅读，带目录、表格、四张架构图；可离线打开并使用浏览器打印。
2. [视觉原型/index.html](视觉原型/index.html)：九个主页面、明暗主题与场景切换，可点击安装预览、依赖确认、任务控制等流程。

[桌面审阅画板](视觉原型/desktop-board.html) 可在1440×960、1360×880、1100×720间切换并将布局等比缩放，便于在窄窗口审阅全部工作区。

[视觉规范](视觉原型/visual-spec.html) 展示色彩、字体、尺寸、组件、反馈、布局与无障碍要求。HTML内嵌样式、图标与原创几何SVG，没有CDN、远程字体、图片或脚本依赖，不需要安装Node/Rust或启动服务器。用Windows 11上的Edge/Chrome双击打开即可；完整解压保留相对目录以使用各文件间链接。

## 原型可演示的流程

- 首页→启动预检→模拟运行/退出；登录失效时引导重新登录。
- 安装：搜索版本、切换正式/快照/历史、选择组件、名称与摘要联动、确认计划→模拟队列。
- 任务：暂停、继续、取消确认、失败重试、步骤详情、模拟校验与完成。
- Mod：已装/发现/资源与光影、筛选、启停、更新差异与依赖确认。
- 实例：修复预览、克隆升级、备份、重命名、删除回收预览。
- 设置：主题、Java内存、下载预算、存储/隐私分类、字段检查与保存反馈。
- 诊断：日志搜索/等级过滤、脱敏导出预览；导入、清理、迁移均只演示计划。

顶部场景选择器包含正常、空态、离线、失败和登录失效。顶部DESIGN工具条、模拟按钮、示例账号与速度都不属于未来产品；刷新重置演示状态。设置离页保护、目标实例选择、账号移除与下载摘要已联动。部分摘要是静态布局数据，原型不模拟完整数据库与所有跨页业务关系；行为真相以规格与AC为准。

## 本次研究的重要结论

- PCL公开latest记录为2.99.0.0（2026-10-20），说明移除MC下载。本项目依用户已确认方向独立保留下载需求；不从其说明推断个人工具的法律结论。
- Minecraft官方版本目录本次latest为26.3/26.4-snapshot-5。Java按版本元数据与Loader约束，不能写死“新版本都是21”；26.1样本声明25。
- Modrinth搜索命中项目不等于具体文件可同时兼容MC/Loader，安装与更新必须做版本级共同筛选与依赖规划。
- Minecraft API接入、自有client ID、权益/profile和Windows实际启动是实施阶段风险门，尚未通过真实账号联调。

详细来源、时间、验证成功与失败均见07文档和研究记录。

## 明确限制

引用旧聊天可以读取用户确认的方向，但助手原规格正文只返回引用标记，无法逐条审阅。本包据此重建基线并明确记录缺口。原型在本机浏览器完成视觉与关键交互检查；实际运行环境为macOS，尚未进行Windows 11原生产品、OAuth、Java安装或Minecraft启动测试。所有产品AC仍待实现与执行，不应把设计包当可运行的启动器。

## 实施一致性要求

每一项完成报告必须含T/FR/UI-ID/命令/AC和实际证据；禁止把静态HTML包装成产品，禁止以mock通过真实验收。原型只定义视觉与代表性交互，65命令/DTO与40AC定义实现义务；未画出的向导细节见12第3节。设计能减少歧义，实际实现仍需要Windows测试与审查。
