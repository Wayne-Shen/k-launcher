# 研究证据说明

核实于2026-10-22，均为公开GET，无登录凭据，无游戏二进制。核实记录中的时间为UTC；中文规格采用北京时间日期。

`original_response_sha256` 是获取时原始响应的摘要，用于来源追踪。`snapshot_kind=original-response` 的文件保留原字节；PCL发布记录及Modrinth响应只保留必要技术字段，已经移除长描述、changelog等内容，因此裁剪件的文件摘要不等于原始响应摘要。许可仅保留链接、摘要和独立设计结论，不镜像许可全文。

版本JSON的来源URL与根目录sha1验证结果保存在核实记录samples中。元数据不等于数字签名，不能单独证明上游供应链安全。

Modrinth `/v2/` 根路径本次404；有效搜索和版本列表接口分别成功200，不能将根路径404解释成服务全不可用。任何未实测端点、安装器执行与Microsoft登录均在研究文档明确列为待验证。

这些快照用于解释设计决策；未来实现应重新获取目录并将具体选择与摘要锁定，不把研究日latest当永久最新。
