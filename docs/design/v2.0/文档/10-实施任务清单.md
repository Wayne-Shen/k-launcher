# 分阶段实施任务清单

这是供后续coding agents执行的工作规格，不是本次执行授权。本次仅交付设计。任务状态全部为“待开始”；每阶段完成后更新此表与验收证据。

开始实施的agent只做用户指定阶段；用户说“开始实现完整方案”才按依赖逐阶段推进，不因一次授权而略过阶段门。任务可在同阶段按模块拆分，但共享数据模型/命令契约由集成负责人先冻结；并行agent需使用不冲突的文件边界与独立审查，不能各自发明schema。

## 关键路径与阶段内分工建议

T00→T06→T10/T12→T13/T14→T20/T21/T22→T25/T26→T30/T32/T33→T35。认证接入可在M0起并行等候，但M3不能跳过。UI工作可用带版本的DTO fixture先行；不得让mock完成态泄漏到真实构建。

可给后续agent的任务范围示例：A负责领域解析与fixture；B负责队列/文件事务；C负责React与无障碍；集成负责人持有schema/IPC/ADR，按阶段合并并审查。此处仅为未来分工建议，不表示本次已启动agents。
