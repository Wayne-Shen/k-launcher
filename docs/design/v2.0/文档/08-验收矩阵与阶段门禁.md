## 3. 测试分层与固定夹具

纯单元：rules/继承解析、Maven坐标、路径规范、依赖求解、状态机合法跃迁。合同测试：每Provider的真实响应裁剪fixture与新字段、缺字段、未知枚举。集成：SQLite+临时目录+本地可控HTTP服务，覆盖Range与错误码、任务重启和文件journal。端到端：Windows真实WebView2/凭据/Java/MC到主菜单。安全类和恢复类不得只用UI mock通过。

联网测试默认不频繁打上游；固定fixture与本地服务跑回归，阶段验收时小流量真实联调并记录时间。任何真实凭据从测试账户的安全存储读取，不进fixture、截图、PR说明。上游漂移与实现缺陷分开归因，但用户不可用时不能宣称通过。
