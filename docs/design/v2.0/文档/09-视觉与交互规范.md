# 视觉与交互规范 · Quiet Desktop

设计基线2.0。K Launcher，面向Windows 11的简洁桌面工作台。色彩与尺寸唯一来源是同包“设计契约/视觉令牌.json”；HTML是高保真视觉参考，JS仅为审阅交互。系统操作仍由后续Rust实现。2.0替代1.0的Moss & Terrain视觉。

## 1. 信息层次与视觉取舍

以白与冷灰建立界面，靛蓝仅用于主要动作、选中与焦点。首页有一幅低饱和原创几何岛屿，其他页面不重复大插画。删除首页口号与重复统计，优先显示实例名、MC/Loader/Java、账号、状态和启动按钮。最近实例用紧凑行，下载使用单张动态摘要；设置/任务/Mod使用信息行与分隔线，避免每个字段包一层卡片。

每个业务区域只有一个主CTA；首页“启动游戏”为实心，“安装游戏”为描边；安装页“预览安装计划”为实心，确认弹窗再显示“确认并安装”。空间不足/未知不能确认；disabled旁常驻原因。危险操作用红色文字或浅红底，并显示具体对象。

原型外部DESIGN工具条、退出预览、模拟提交是审阅工具，不属于产品。产品页面不出现Rust/IPC/schema/“演示”等词。初次使用、错误、空态用短句提供下一步；原型注释与真实文案可在12追踪表中区分。

## 5. 状态与组件契约

按钮：normal/hover/pressed/focus/pending/disabled；pending保留宽度、禁重复提交、文字明确“生成计划中”。焦点3px，offset3px。禁用按钮的原因在近邻文本或aria-describedby，不能只有灰色。任务Committing时显示“正在保存安装结果”，无可点击的暂停/取消。

输入：独立label、help与error；错误不替换label，提交聚焦首个错误；字符计数按Unicode规则。select/radio真实暴露checked/selected。标签页用tablist/tab/tabpanel与左右键/Enter，或导航链接语义；不能混用“按钮外观”和不存在的aria角色。

模态：打开聚焦标题或首个合理输入；Tab/Shift+Tab圈定，背景inert，Esc关闭不产生副作用的预览；关闭返回触发者（触发者已卸载则页面h1）。危险操作默认焦点取消。后端提交已接受时关闭弹窗只关闭视图，不取消任务。

设置：草稿跨分类保留；离页提供保存/放弃/继续编辑；主题即时预览，放弃恢复。保存失败保留草稿、错误和旧持久值。原型能演示主要草稿行为；全部SettingsValues以11为准，不以画出的字段子集裁剪产品功能。

进度：未知总量不画百分比，显示“已下载X / 总量待确认”；暂停与离线速度为0；校验/安装用步骤或不定进度；失败展示错误码、影响和恢复按钮；结束结果常驻卡片，toast辅助显示3.4秒。下载状态不复用实例Ready标签。

## 6. 设计审阅场景与产品状态

顶部可切正常/空/离线/失败/登录失效。原型模拟的空态是整页fixture，不是产品删除全部数据。移除账号仅清演示账号；切换Mod实例不会继续展示上个Fabric实例的内容。原型少量列表仍为固定样例，非所有跨页业务状态的完整模拟。

需要逐项实现的其他状态：加载与取消、stale目录、未知大小、限流倒计时、处理器不可暂停、提交中、Interrupted恢复、外部Mod修改、登录权限受限、无档案、secret清理失败、未保存设置。画法使用本文件组件状态，行为以05/11/12为准。原型没有完整展开的向导不得被删去，见12第3节。

## 7. 视觉与功能验收方法

AC40要求每个UI-ID有实际React→Rust→状态反馈闭环，不能只展示设计HTML。提交1440×960、1360×880、1100×720的浅/深色代表页面截图，至少覆盖首页、安装、Mod、任务、设置；200%缩放检查无信息丢失，窄表格可滚动。鼠标、键盘、高对比、减少动画分别验证。布局位置/尺寸以token为准，Windows字体渲染差异不要求逐像素相同；关键几何误差≤4DIP，不能换色/缩字来掩盖布局问题。

设计审阅工具、模拟按钮、版本演示算法不能出现在真实构建。最终验证范围仍是Windows应用，不是本轮静态浏览器预览。
