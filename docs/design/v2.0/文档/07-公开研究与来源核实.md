## 3. Minecraft与Java（A/B）

[R09 官方版本根目录](https://piston-meta.mojang.com/mc/game/version_manifest_v2.json) 实测HTTP200，latest.release=26.3、latest.snapshot=26.4-snapshot-5。保存1.21.1、26.1和快照JSON，逐个与根目录sha1验证相符。1.21.1声明majorVersion21、component java-runtime-delta；26.1与快照声明majorVersion25、component java-runtime-epsilon。样本不是全版本兼容认证。

[R04 官方26.1说明](https://feedback.minecraft.net/hc/en-us/articles/44551668333837-Minecraft-Java-Edition-26-1) 明确Java25及JVM默认改变。结论：不要写死“1.20.5以后全部Java21”；保持版本与Loader约束求交。默认内存与GC也不能把某一版本策略无条件推广到所有实例。

[R10 Adoptium API cookbook](https://github.com/adoptium/api.adoptium.net/blob/main/docs/cookbook.adoc) 提供按平台/架构/major选运行时与checksum的流程。本次Windows x64 Java25 JDK assets请求HTTP200；设计固定具体build及package SHA256再下载ZIP，不默认修改系统Java。

Minecraft主jar与资源通过官方manifest引用下载；本包未下载游戏二进制，不含游戏资源或账号数据。完整下载链在M2用测试实例验证，不能仅因为版本JSON可获取就声称能启动。

## 5. Microsoft/Xbox/Minecraft登录（B/C）

[R17 Microsoft Authorization Code+PKCE](https://learn.microsoft.com/en-us/entra/identity-platform/v2-oauth2-auth-code-flow) 支持桌面应用；[R18 Device Code](https://learn.microsoft.com/en-us/entra/identity-platform/v2-oauth2-device-code) 规定轮询、过期和slow_down。设计选系统浏览器PKCE，设备码为经过自有应用验证后才开放的备用路径；不把登录嵌进有IPC权限的WebView。

Minecraft专用交换链的公开官方资料并不完整。采用维护方客户端源码作为交叉证据，而不误引GDK/XUser文档当成Java第三方启动器合同。例如 [R19 Prism profile步骤](https://github.com/PrismLauncher/PrismLauncher/blob/develop/launcher/minecraft/auth/steps/MinecraftProfileStep.cpp) 访问 `api.minecraftservices.com/minecraft/profile`，将profile404作为与请求失败不同的账号状态。

规划端点：Microsoft consumers OAuth authorize/token；`user.auth.xboxlive.com/user/authenticate`；`xsts.auth.xboxlive.com/xsts/authorize`；`api.minecraftservices.com/authentication/login_with_xbox`；`entitlements/mcstore`与`minecraft/profile`。这些需要在M0/M3用自有获准client ID确认参数、scope、权限与Game Pass行为；本包未实测敏感POST，也不借用其他启动器ID。

[R20 Minecraft Java支持目录](https://help.minecraft.net/hc/en-us/sections/44460521913485) 的搜索索引列出Game Service API Review/Application主题，但当前网页正文动态加载，未成功读取该文章完整审批条件。因此“自有应用是否获准”是明确开放项，不能写成“个人使用自动免审批”。M0交付须记录实际申请入口与结果；403需区分接入、账号与服务状态。

## 6. Modrinth、整合包与CurseForge（A/B）

[R21 API总览](https://docs.modrinth.com/api/)：公开读请求通常无需账号token；请求需独特User-Agent；根据rate limit响应头调速。文档当次说明300次/分钟，本设计本地预算更保守，并以服务端实际响应为准。GET `/v2/` 在本次返回404；这不代表全部服务不可用，应使用有效业务端点做探测。

[R22 搜索](https://docs.modrinth.com/api/operations/searchprojects/) 定义facets；[R23 版本列表](https://docs.modrinth.com/api/operations/getprojectversions/) 提供files与dependencies；[R24 Hash识别](https://docs.modrinth.com/api/operations/versionfromhash/) 提供本地文件映射。本次search(sodium,limit1)与project/sodium/version(1.21.1,fabric)均GET200，后者返回22条样本；版本候选不等于依赖已求解。

[R25 mrpack格式](https://support.modrinth.com/en/articles/8802351-modrinth-modpack-format-mrpack)：清单、文件hash、环境与覆盖目录是安装依据。设计按客户端环境处理，先路径预审后下载与应用覆盖；未知必需依赖阻断。

[R26 CurseForge API](https://docs.curseforge.com/rest-api/) 需要API key；文件下载能力可能受上游策略限制。设计不承诺所有CF整合包一键下载，提供手动补齐清单。未取得key、未实测下载权限，故仅列条件支持。

## 7. Tauri/Windows（B/C）

[R27 Capabilities](https://v2.tauri.app/security/capabilities/) 用于限制窗口/IPC权限，但Rust自定义命令仍须做业务与输入校验。[R28 Windows Installer](https://v2.tauri.app/distribute/windows-installer/) 描述WebView2依赖与Windows打包。设计采用每用户安装、WebView2检测/修复提示，不默认系统权限；签名与自动更新分发不在个人版首轮范围。

技术版本号只锁大方向Tauri2/React/TypeScript/Rust；真正开始实施时检查当前兼容版本并锁依赖，不能把研究日称为“所有依赖最新”。本次本机为macOS，未进行Windows 11的进程/凭据/WebView2运行验证。

## 8. 研究结论与实施前复核清单

- 下载保留为产品主路径，不能因PCL的新版本变化而删去FR-03。
- 版本与Java均按元数据，精确Loader约束和固定fixture复核；网页概括冲突时停止并查具体版本。
- Mod兼容与更新按具体文件求交，保留旧文件回滚；整合包越界检查先于创建输出。
- OAuth成功、Minecraft API接入、权益、profile与实际启动是不同的验收门。
- M0优先消除账号接入、安装器行为、Windows路径/凭据这三类高风险未知，再推进主闭环。
- 后续agents每次重新联网核实时补checked_at、来源与差异记录，不覆盖原始研究证据；本次快照仅供解释设计，不作为永久版本列表。
