# 全包复审与2.0修订记录

日期：2026-10-22。复审范围：原10份中文规格、AGENTS/README、9页原型、视觉规范、架构图、研究证据及任务/验收引用。当前仅修改设计交付，未开始产品编码。

## 本轮结论

1.0已有主要功能与风险分析，但若直接交给不同agent，接口细节、重试语义、事件恢复和UI状态会产生分叉。2.0补齐实施契约与页面追踪，并用新的Quiet Desktop视觉替换旧方案。现在共12份规格、65个命令、38组操作、40条产品AC与48项M0–M6任务。产品AC全部仍待实施；不能由本轮静态原型检查代替。

## 研究证据复核边界

已复读07文档和保存的公开接口记录，确认设计仍保留下载硬性需求、精确Java/Loader约束、Modrinth版本级求交与自有认证接入门。本轮没有重复联网抓取全部接口，也没有更新原始checked_at；仍引用2026-10-22上一轮公开GET证据。来源可用性、最新版本与审批状态必须由M0按实施时间复核，不将“复审设计”写成“重新联调成功”。

旧聊天助手正文不可访问的缺口没有消失；只能核对已确认用户方向，不能声称找回旧规格。

## 保留的实施前验证项

- 自有Microsoft应用与Minecraft API实际可用性、Game Pass/无档案/无权益的真实响应。
- Win11 DPAPI、ACL、文件/进程身份、WebView2及中文/长路径联调。
- 固定Loader安装器处理器、准确输出与失败重入；旧版/Quilt仍按L3专项。
- Windows原生字体、125/150/200%缩放、高对比与辅助技术测试。
- 从真实目录导入并到游戏主菜单的完整闭环、性能与故障注入。

这些是实现验收条件，不是当前允许agent自由猜测的设计选项。未验证时标阻塞/尚未验证，不更改硬性要求。
