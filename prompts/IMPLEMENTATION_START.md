## 目标与范围

Windows 11 x64、本地个人自用的Minecraft Java启动器，产品名固定为 **K Launcher**，技术路线为Rust + Tauri 2 + React + TypeScript。下载Minecraft是不可删减的核心需求。完整实现设计中的P0/P1；AI、皮肤等M7增强不属于当前范围。

## 先读取并冻结基线

1. 核对`docs/design/v2.0/`完整性与`文件清单与摘要.json`。若文件缺失或无法访问，明确指出缺什么，不根据聊天摘要或经验自行补造设计。
2. 阅读仓库根目录`AGENTS.md`、设计目录README与AGENTS、审查与修订记录及全部12份规格。重点核对文档11《实施契约与一致性决策》、文档12《页面操作与实现追踪》和文档10《实施任务清单》。
3. 使用“设计契约”中的65个命令、38组UI操作追踪和视觉令牌作为共同契约。行为与视觉优先级严格按设计包规定；发现正文、JSON或原型冲突时先记录并解决，不自行选择。
4. **设计与后续实施均在当前同一个仓库。** 产品代码在仓库根目录的正式项目结构中实现，阶段证据放`implementation/M0/`等目录；设计目录保持可审计基线，不在其中铺设产品项目。不得另建脱离基线的产品仓库。
5. 不得把静态HTML或其中的模拟逻辑包装成产品。产品显示名为K Launcher，默认Windows目录标识为KLauncher；本次更名没有改变v2.0功能、协议或验收编号。
